# BornCode — ชุดโลโก้และแนวทางการใช้

`borncode-logo.svg` คือไฟล์ต้นฉบับ (master) ทุกไฟล์ในชุดนี้เป็นสไตล์ **Soft Glass** แบบเรียบ โทนฟ้า–ขาว (แผ่นแก้วฝ้ามุมมน เส้นแสงบางๆ ที่ขอบ เงานุ่ม ไม่มีพื้นมืดหรือแสงสีอื่น)

สเปกการออกแบบทั้งหมด (สี, ฟอนต์, โครงสร้างโลโก้, สูตรแก้ว, CSS สำหรับเว็บ) อยู่ใน [DESIGN.md](DESIGN.md)

โลโก้แบบสีเรียบ (flat) รุ่นก่อนหน้ายังอยู่ในประวัติ git ที่ commit `e31f34e` ถ้าต้องใช้งานพิมพ์สีเดียว ปั๊ม หรือสกรีน ให้ดึงแบบนั้นกลับมาใช้

## โครงสร้างไฟล์

```
borncode-logo/
├── borncode-logo.svg          ต้นฉบับ (เหมือน svg/borncode-stacked-color.svg)
├── DESIGN.md                  สเปกการออกแบบ / design system
├── svg/                       ไฟล์เวกเตอร์ ใช้ทำเว็บ สไลด์ งานดิจิทัล ส่งดีไซเนอร์
├── png/512 | 1024 | 2048/     PNG พื้นโปร่งใส กว้าง 512 / 1024 / 2048 px
├── web/                       favicon, ไอคอนแอป, site.webmanifest
└── social/                    รูปแชร์ลิงก์ (OG) และรูปโปรไฟล์
```

## รูปแบบโลโก้

| ชื่อไฟล์ | ลักษณะ | ใช้เมื่อ |
|---|---|---|
| `borncode-stacked-*` | สามเหลี่ยมบน ตัวอักษรล่าง | โลโก้หลัก หน้าปก โปสเตอร์ นามบัตร |
| `borncode-horizontal-*` | สามเหลี่ยมซ้าย ตัวอักษรขวา | แถบเมนูเว็บไซต์ หัวกระดาษ อีเมล |
| `borncode-mark-*` | สามเหลี่ยมอย่างเดียว | ไอคอน รูปโปรไฟล์ ลายน้ำ |
| `borncode-wordmark-*` | ตัวอักษรอย่างเดียว | พื้นที่แคบ หรือมีสามเหลี่ยมอยู่แล้วในหน้า |

| สี | ใช้เมื่อ |
|---|---|
| `color` | แก้วไล่สีตามชั้นเดิม ตัวอักษรน้ำเงินเรียบ · พื้นขาวหรือพื้นอ่อน (ใช้แบบนี้เป็นหลัก) |
| `mono` | แก้วสีน้ำเงิน `#2D4799` ทุกชั้น · พื้นอ่อน เมื่ออยากได้โทนเดียว |
| `white` | แก้วฝ้าสีขาว ตัวอักษรขาว · บนพื้นเข้มหรือบนรูปภาพ |
| `black` | แก้วสีดำควัน ตัวอักษรดำ · พื้นอ่อนแบบโทนขาวดำ |

## ข้อควรรู้ของสไตล์แก้ว

- เอฟเฟกต์แก้วสวยที่สุดเมื่อมีสีหรือแสงอยู่ด้านหลัง บนพื้นเรียบสีเดียวจะดูเป็นแก้วน้อยลง
- ที่ขนาดเล็กมาก (favicon 16–32 px) รายละเอียดแก้วจะหาย เห็นเป็นสามเหลี่ยมไล่สีธรรมดา
- งานพิมพ์สีเดียว ปั๊ม สกรีน ปักผ้า ใช้แบบแก้วไม่ได้ ให้ใช้แบบ flat จาก commit `e31f34e`
- ไฟล์ SVG ใช้ gradient, clipPath และ filter บางโปรแกรมรุ่นเก่า (หรืออีเมลบางตัว) อาจแสดงเงาไม่ครบ ถ้าเจอให้ใช้ PNG แทน
- แบบ `white` ใช้บนพื้นสีเข้มหรือพื้นน้ำเงินเท่านั้น (บนพื้นขาวจะมองไม่เห็น)

## ระยะปลอดภัยและขนาดเล็กสุด

- **ระยะปลอดภัย:** เว้นที่ว่างรอบโลโก้อย่างน้อยเท่าความสูงตัว **B** ห้ามมีข้อความหรือภาพอื่นเข้ามาในระยะนี้
- **ขนาดเล็กสุด (จอ):** stacked กว้าง 120 px · horizontal กว้าง 140 px · mark กว้าง 24 px
- **ขนาดเล็กสุด (พิมพ์):** stacked กว้าง 25 มม. · horizontal กว้าง 30 มม.

## ห้ามทำ

- ยืด บีบ หรือหมุนโลโก้
- เปลี่ยนสีชั้นของสามเหลี่ยม หรือเปลี่ยนฟอนต์
- ใส่เงา ขอบ หรือเอฟเฟกต์เพิ่มจากที่มีในไฟล์
- วางแบบ `color` บนพื้นเข้มหรือพื้นลาย (ให้ใช้ `white`)

## ติดตั้งบนเว็บไซต์

คัดลอกไฟล์ทั้งหมดใน `web/` และ `social/og-image-1200x630.png` ไปไว้ที่ root ของเว็บ แล้วใส่ใน `<head>` (เปลี่ยน `YOUR-DOMAIN` เป็นโดเมนจริง):

```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#2D4799">
<meta property="og:image" content="https://YOUR-DOMAIN/og-image-1200x630.png">
```

โลโก้บนแถบเมนู (คัดลอก `svg/borncode-horizontal-color.svg` ไปไว้ที่ root ของเว็บ):

```html
<img src="/borncode-horizontal-color.svg" alt="BornCode" height="40">
```

## สำหรับ dev: ใช้เป็นแบบอ้างอิง (design reference)

- **หน้าแดชบอร์ด (เมนูสั้น → ยาวเมื่อค้างเมาส์):** เปิด `skills/borncode-rebrand/assets/examples/dashboard-formal.html` ในเบราว์เซอร์เพื่อดูหน้าตัวอย่าง CSS อยู่ที่ `skills/borncode-rebrand/assets/css/borncode-dashboard.css` สเปกอยู่ใน DESIGN.md หัวข้อ 5.1
